User account deletion — self-serve flow replacing manual BD review
Feature: User Remove Account · Status: Draft for review
Context. Users currently have no self-serve way to delete their account. This feature introduces a structured deletion flow: the system checks for active orders, pending withdrawals, open disputes, and remaining balance before allowing deletion. If blockers exist, the user must resolve them and resubmit. Once cleared, a 14-day cooling-off period begins before the account is permanently deleted.
